# Supermarket Simulation
Лабораторна робота з об'єктно-орієнтованого програмування (ООП) на Python.
## Учасники команди
- Мельник Кіріл
- Івасюнько Нікіта
- Дужак Олександр
## Опис проєкту
Програма моделює роботу супермаркету. Реалізовано класи для управління товарами, знижками, покупцями, замовленнями та загальною симуляцією процесу покупки.
